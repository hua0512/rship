`webdav` 后端（`backend-webdav`）内置 6 种厂商配置，自动适配各服务端 HTTP/WebDAV 语义：在 Nextcloud 与 OwnCloud 上启用 **Chunked Upload v2** 断点续传流水线，同时兼顾群晖 NAS、Alist/OpenList、InfiniCloud 及通用 DAV 服务的传输速度与稳定性。

## 配置示例

<CodeTabs>
<CodeTab label="Nextcloud / OwnCloud">

```bash
# 自动推导 /remote.php/dav/uploads/<user> 以启用 Chunked Upload v2
rship auth webdav nc \
  --vendor nextcloud \
  --url https://cloud.example.com/remote.php/dav/files/alice \
  --username alice \
  --password "<APP_PASSWORD>"

rship about nc:
```

</CodeTab>
<CodeTab label="群晖 / Alist / Bearer 令牌">

```bash
# 群晖 DSM WebDAV Server
rship auth webdav syno \
  --vendor synology \
  --url https://nas.example.com:5006/backups \
  --username backup-bot

# Alist / OpenList 或通用 Bearer 令牌 WebDAV
rship auth webdav alist \
  --vendor alist \
  --url https://alist.example.com/dav \
  --bearer-token "<TOKEN>"
```

</CodeTab>
</CodeTabs>

## 支持的厂商配置（`--vendor`）

| 厂商 | Chunked Upload v2 | 服务端 `COPY` | `PROPFIND` 配额 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| `nextcloud` | 支持（`10–100 MiB` 分片） | 支持 | 支持 | 建议使用 Nextcloud 应用专用密码 |
| `owncloud` | 支持（`10–100 MiB` 分片） | 支持 | 支持 | 路径自定义时可通过 `--chunked-upload-root` 覆盖 |
| `alist` | 流式 `PUT` | 支持 | 部分支持 | 同时接受别名 `openlist` |
| `synology` | 流式 `PUT` | 支持 | 支持 | 适配群晖 HTTPS 端口 `:5006` |
| `infinicloud` | 流式 `PUT` | 支持 | 支持 | 兼容 TeraCLOUD / InfiniCloud WebDAV |
| `generic` | 流式 `PUT` | 支持 | 支持 | 适用于 Nginx / Caddy / Apache DAV 的默认选项 |

## 参数参考（`rship auth webdav`）

| 参数 | 默认值 | 说明 |
| :--- | :--- | :--- |
| `<REMOTE>` | — | 远端逻辑名称（如 `nc`、`nas`） |
| `--url` | 必填 | WebDAV 基础 URL |
| `--vendor` | `generic` | 可选 `nextcloud`、`owncloud`、`alist`、`synology`、`infinicloud`、`generic` |
| `--username` | 无 | Basic 认证用户名 |
| `--password` | 无 | Basic 认证密码 |
| `--bearer-token` | 无 | HTTP Bearer 认证令牌（可替代用户名/密码） |
| `--chunked-upload-root` | 自动推导 | 显式指定 Nextcloud/OwnCloud 的 `/remote.php/dav/uploads/<user>` 地址 |

## 协议实现细节

- **Nextcloud / OwnCloud Chunked Upload v2**：超过 `10 MiB` 的文件默认按 `10 MiB` 分片（上限 `100 MiB`）上传至 `/remote.php/dav/uploads/<user>/<op_id>`，完成后原子 `MOVE` 至目标路径，避免传输中断残留损坏文件。
- **自动路径推导**：传入 `https://host/remote.php/dav/files/alice[/subpath]` 时，若未设置 `--chunked-upload-root`，自动解析对应的 `/remote.php/dav/uploads/alice` 分片上传根目录。
- **企业代理与 NAS 自签证书**：可直接配合全局参数 `--ca-cert ./nas-ca.pem` 与 `--proxy` 使用。
