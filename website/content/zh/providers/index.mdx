## 按 Feature 裁剪编译

在嵌入 `rship` Rust SDK 或构建极致精简的 CLI 时，可以只启用实际使用的存储后端（全部 12 个 S3 预设参数详见 [S3 及 S3 兼容存储（12 预设）](/providers/s3)）：

```bash
# 仅保留 Local 与 S3 驱动的极简 CLI（零 Google / Azure / SFTP / WebDAV 代码体积）
cargo build --release -p rship-cli --no-default-features --features backend-local,backend-s3

# 极简 Rust SDK（默认仅启用 local，零 HTTP / SQLite / Keyring 依赖）
# Cargo.toml:
# rship = { git = "https://github.com/hua0512/rship", features = ["s3", "sqlite"] }
```

希望贡献或集成新的存储后端？欢迎参考 [4 步接入新存储后端](/architecture/adding-a-provider)。
