`s3` 后端（`backend-s3`）通过内置的服务商能力矩阵支持 Amazon S3 及 11 种 S3 兼容对象存储。预设准确封装了各厂商的协议细节，例如 Cloudflare R2 强制非末尾分片等长、条件写入与硬件加速校验和。

## 快速配置

<CodeTabs>
<CodeTab label="Cloudflare R2">

```bash
rship auth s3 r2 \
  --provider r2 \
  --bucket backups \
  --region auto \
  --endpoint https://<ACCOUNT_ID>.r2.cloudflarestorage.com \
  --access-key-id <ACCESS_KEY_ID> \
  --secret-access-key <SECRET_ACCESS_KEY>

rship about r2:backups
```

</CodeTab>
<CodeTab label="AWS S3 (IAM 环境变量 / 密钥)">

```bash
# 从环境变量读取 AWS_ACCESS_KEY_ID / AWS_SECRET_ACCESS_KEY
rship auth s3 aws-prod \
  --provider aws \
  --bucket corp-archive \
  --region us-east-1 \
  --env-auth

# 或直接传入显式密钥与可选 STS 会话令牌
rship auth s3 aws-prod --provider aws --bucket corp-archive --region us-east-1
```

</CodeTab>
<CodeTab label="MinIO / 自建服务">

```bash
rship auth s3 minio \
  --provider minio \
  --bucket media \
  --endpoint http://127.0.0.1:9000 \
  --access-key-id minioadmin \
  --secret-access-key minioadmin
```

</CodeTab>
<CodeTab label="Backblaze B2 / 阿里云 OSS">

```bash
# Backblaze B2 S3 兼容 API
rship auth s3 b2 --provider b2 --bucket cold-backups --region us-west-004

# 阿里云 OSS（可选 --prefix 限定路径前缀）
rship auth s3 oss --provider oss --bucket prod-data --region oss-cn-hangzhou --prefix backups/
```

</CodeTab>
</CodeTabs>

## 12 个内置预设

在 `rship auth s3` 中传入 `--provider <preset>` 即可选用对应预设。所有预设字段均可通过 `--region`、`--endpoint`、`--force-path-style` 或 `--strict-sigv4` 显式覆盖。

| 预设 | 服务商 | 默认区域 | 寻址方式 | 单对象上限 | 校验和与特性 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `aws` | Amazon S3 | `us-east-1` | Virtual-hosted | `~48.8 TiB` | `CRC64NVME`、`CRC32C`、`SHA256`、`MD5`；支持 `If-None-Match` 与 `If-Match` |
| `r2` | Cloudflare R2 | `auto` | Path-style | `5 TiB` | `CRC32C`、`SHA256`、`MD5`；**强制非末尾分片等长**；支持 `If-None-Match` 与 `If-Match` |
| `minio` | MinIO / Silo | `us-east-1` | Path-style | `5 TiB` | `CRC32C`、`SHA256`、`MD5`；支持 `If-None-Match` 与 `If-Match` |
| `oss` | 阿里云 OSS | `oss-cn-hangzhou` | Virtual-hosted | `~48.8 TiB` | `SHA256`、`MD5` |
| `b2` | Backblaze B2 | `us-west-000` | Path-style | `10 TiB` | `SHA256`、`SHA1`、`MD5` |
| `wasabi` | Wasabi Hot Cloud | `us-east-1` | Virtual-hosted | `5 TiB` | `SHA256`、`MD5`；支持 `If-None-Match` |
| `digitalocean` | DigitalOcean Spaces | `nyc3` | Virtual-hosted | `5 TiB` | `SHA256`、`MD5` |
| `cos` | 腾讯云 COS | `ap-guangzhou` | Virtual-hosted | `~48.8 TiB` | `SHA256`、`MD5` |
| `tigris` | Tigris Storage | `auto` | Virtual-hosted | `5 TiB` | 端点 `fly.storage.tigris.dev`；`CRC32C`、`SHA256`、`MD5`；支持 `If-None-Match` 与 `If-Match` |
| `scaleway` | Scaleway Object | `fr-par` | Virtual-hosted | `5 TiB` | `SHA256`、`MD5` |
| `hetzner` | Hetzner Object | `fsn1` | Virtual-hosted | `5 TiB` | `SHA256`、`MD5` |
| `generic` | Ceph / Garage / SeaweedFS | `us-east-1` | Path-style | `5 TiB` | `SHA256`、`MD5`（别名：`other`、`ceph`、`seaweedfs`、`garage`） |

## 认证与参数 (`rship auth s3`)

| 参数 | 默认值 | 说明 |
| :--- | :--- | :--- |
| `<REMOTE>` | — | 远端逻辑名称（如 `r2`、`aws-backups`） |
| `--provider` | `aws` | 上表 12 个服务商预设之一 |
| `--bucket` | 可选 | 默认存储桶；留空时可通过 `remote:bucket/path` 访问多个存储桶 |
| `--prefix` | 空 | 存储桶内可选键前缀，用于限定操作范围 |
| `--region` | 预设默认值 | AWS 或对应厂商的区域标识 |
| `--endpoint` | 预设默认值 | 自定义端点 URL（`r2`、`minio`、`generic` 必填） |
| `--force-path-style` | 预设默认值 | 强制使用路径风格 `endpoint/bucket/key`（`true`）或虚拟主机风格 `bucket.endpoint/key`（`false`） |
| `--env-auth` | `false` | 从环境变量读取 `AWS_ACCESS_KEY_ID`、`AWS_SECRET_ACCESS_KEY` 与 `AWS_SESSION_TOKEN` |
| `--strict-sigv4` | `false` | 即使在 HTTPS 下也强制计算完整载荷的 SHA-256 哈希 |
| `--storage-class` | 无 | 写入对象时附加 `x-amz-storage-class` 请求头（如 `STANDARD_IA`、`GLACIER`） |

## 协议细节与崩溃断点续传

- **单次上传与并发多段上传**：`<= 16 MiB`（`single_shot_max_bytes`）的对象直接走单次 `PutObject`；更大文件通过 `CreateMultipartUpload` + 并发 `UploadPart` 流式上传（默认 `--part-concurrency 4`，单分片默认 `16 MiB`，最小 `5 MiB`，上限 `10,000` 个分片）。
- **分页 `ListParts` 崩溃续传**：Upload ID 与已完成分片的 ETag 及偏移量均记入 SQLite WAL。进程崩溃或遭遇 `SIGKILL` 后，`rship` 会分页查询 `ListParts`，仅补传缺失分片再调用 `CompleteMultipartUpload`。执行 `rship gc --all` 可中止远端残留的未完成多段上传。
- **零 `aws-chunked` 开销**：默认（`PayloadSigningMode::Auto`）在 HTTPS 上传时发送 `x-amz-content-sha256: UNSIGNED-PAYLOAD`，省去额外的载荷哈希扫描；遇到明文 `http://` 端点或启用 `--strict-sigv4` 时，自动切换为流式 SHA-256 载荷摘要。
- **服务端拷贝与范围读取**：同远端拷贝在 `5 GiB` 以内走 `CopyObject`，超过 `5 GiB` 自动切换多段 `UploadPartCopy`。`rship cat` 支持 HTTP `Range` 字节偏移读取。
- **从 rclone 迁移**：现有 `type = s3` 的 `[remote]` 配置（含 `provider` / `endpoint` / `access_key_id` / `secret_access_key`）可通过 `rship config import-rclone` 直接导入。
