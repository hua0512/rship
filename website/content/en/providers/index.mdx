## Feature-Gated Compilation

When embedding the `rship` Rust SDK or building a minimal CLI binary, include only the backends you use (details on all 12 S3 presets live in [S3 & S3-Compatible (12 Presets)](/providers/s3)):

```bash
# Minimal CLI with Local + S3 only (zero Google/Azure/SFTP/WebDAV code)
cargo build --release -p rship-cli --no-default-features --features backend-local,backend-s3

# Minimal SDK crate (defaults to local-only, zero HTTP/SQLite/keyring)
# Cargo.toml:
# rship = { git = "https://github.com/hua0512/rship", features = ["s3", "sqlite"] }
```

Want to integrate another backend? Follow the [4-Step Guide to Adding a Provider](/architecture/adding-a-provider).
